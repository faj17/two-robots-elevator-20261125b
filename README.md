The setup is a robot's proximity sensor flagging the crowding — a concrete machine complaint. The twist lands in the second clause: the robot's own manners subroutine vetoes saying anything about it, so the machine is trapped between its sensor and its politeness, and the awkwardness is the thing neither robot wants to name.
